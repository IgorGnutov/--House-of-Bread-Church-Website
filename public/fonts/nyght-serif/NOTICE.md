# Nyght Serif — provenance notice

Nyght Serif is designed by Maksym Kobuzan (Tunera Type Foundry) and distributed under the
SIL Open Font License, Version 1.1.

The `.woff2` files in this folder were pulled from a public mirror
(https://github.com/sofiyakorochkina03/-Nyght-Serif) because no official CDN or download
endpoint for this font could be located at the time of integration. That mirror did not
ship an `OFL.txt`, so authorship/license terms above are asserted based on third-party
font-catalog listings (e.g. bestfreefonts.com / justfreefonts.com), not a license file
bundled with the source repo. If you obtain the official release (e.g. directly from
Tunera Type Foundry) at some point, prefer replacing these files with that copy and
including its bundled `OFL.txt`.

Only the weights actually used on this site were pulled in: Regular, Bold, and their
italics.
